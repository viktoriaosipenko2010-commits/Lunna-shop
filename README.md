# LUNNA — магазин аксесуарів

Навчальний адаптивний сайт українською мовою.

## Сторінки
- Головна — `index.html`
- Каталог із фільтрами та сортуванням — `catalog.html`
- Новинки — `new.html`
- Про нас — `about.html`
- Доставка й оплата — `delivery.html`
- Контакти — `contacts.html`

## Як працює
Статичний сайт на HTML, CSS і JavaScript. Кошик демонстраційний і зберігає вибір у браузері. Форми не надсилають дані, реальної оплати й оформлення замовлень немає. Ціни та товари наведені для навчального прикладу.

## Публікація
У GitHub відкрий Settings → Pages, обери Deploy from a branch, branch `main`, folder `/ (root)` і натисни Save. Після розгортання GitHub покаже адресу сайту.
